The Mediator concept is an alternative to SOA (Service-Oriented Architecture), but this library goes one step further by providing abstraction via HTTP for applications using backend for a frontend pattern. It is best suited for .NET Blazor WASM applications.

## Where to start
New here? Start with [Why Pipaslot.Mediator](1.-Why-Pipaslot.Mediator.md) and follow the chapters in order using the sidebar navigation.

A runnable example application (Server + Client Blazor WASM + Shared) is available in the [`Demo/`](https://github.com/pipaslot/Mediator/tree/main/Demo) folder of the repository.
