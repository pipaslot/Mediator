## Control handler status
There may be specific scenarios when you want to prevent throwing exceptions from the handler because they are captured by error handling middleware and converted into notifications appearing in the UI. You can instruct the mediator to return the unsuccessful status code via IMediatorContextAccessor.
Just 

```
public class MyHandler
{
   private readonly IMediatorContextAccessor _mca;

   public MyHandler(IMediatorContextAccessor mca){
      _mca = mca;
   }

   public async Task Handle(MyAction action, CancellationToken cancellationToken){
      try{
         //Operation causing exceptions in some cases
      }catch(MyException){
         _mca.Context.Status = ExecutionStatus.Failed;
      }
   }
}
```
