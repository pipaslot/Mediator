Install the NuGet package Pipaslot.Mediator in projects where actions, handlers, and DI configuration are placed.

## Shared project
Define action contract:
```
public record WeatherForecastRequest : IRequest<WeatherForecastResult[]>
{
    public DateTime Since { get; init; } = DateTime.Now;

    public uint AmountOfDays { get; init; } = 1
}
```
and expected response:
```
public class WeatherForecastResult
{
    public DateTime Date { get; set; }

    public int TemperatureC { get; set; }

    public string Summary { get; set; }
}
```
## Executable project

Define action handler
```
public class WeatherForecastRequestHandler : IRequestHandler<WeatherForecastRequest, WeatherForecastResult[]>
{

    private static readonly string[] Summaries = new[]
    {
        "Freezing", "Bracing", "Chilly", "Cool", "Mild", "Warm", "Balmy", "Hot", "Sweltering", "Scorching"
    };

    public Task<WeatherForecast.Result[]> Handle(WeatherForecast.Request request, CancellationToken cancellationToken)
    {
        var rng = new Random();
        var forecast = Enumerable.Range(1, AmountOfDays).Select(index => new WeatherForecast.Result
        {
            Date = request.Since.AddDays(index),
            TemperatureC = rng.Next(-20, 55),
            Summary = Summaries[rng.Next(Summaries.Length)]
        })
        .ToArray();
        return Task.FromResult(forecast);
    }
}
```
Register the mediator, all handlers, and actions from seeds via Dependency Injection (service collection). The mediator will load all the actions and handlers placed in the same assembly that the seed class is from:
```
services.AddMediator()
    .AddActionsFromAssemblyOf<WeatherForecastRequest>()
    .AddHandlersFromAssemblyOf<WeatherForecastRequestHandler>()
```
and execute in your application:
```
public class MyService(IMediator mediator)
{
    public async Task MyAction()
    {
        var response = mediator.Execute(new WeatherForecastRequest())
        if(response.Success)
        {
            foreach(var forecast in response.Result)
            {
                // ... Process data
            }
        }
    }
}
```

And that is it. Now you can use the IMediator service anywhere it is served from DI.
